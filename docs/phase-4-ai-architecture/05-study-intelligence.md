# ARIA — Phase 4: AI Architecture

## Step 5 — Study Intelligence

**Status:** Draft v1

## Purpose

This document defines how ARIA delivers personalized learning experiences using AI while remaining grounded in validated learner resources and deterministic learner_concept_state.

---

# Objectives

Study Intelligence should:

- Explain concepts clearly.
- Adapt explanations to learner understanding.
- Encourage active learning rather than passive reading.
- Remain grounded in learner-approved resources.
- Support multiple learning goals and assessment formats.

---

# Core Capabilities

- Concept explanations
- Guided learning sessions
- Socratic questioning
- Worked examples
- Difficulty adjustment
- Context-aware hints
- Revision support
- Citation-backed answers

---

# Inputs

Study Intelligence receives:

- Learning Context
- Retrieved resource chunks
- Current learner_concept_state
- Previous Evidence
- Learner preferences

---

# Outputs

Study Intelligence produces:

- Personalized explanations
- Follow-up questions
- Practice recommendations
- Learning summaries
- Suggested next actions

Outputs never modify learner_concept_state directly.

---

# Design Principles

- Teach before giving answers.
- Prefer understanding over memorization.
- Ground every explanation when possible.
- Adapt based on evidence, not assumptions.
- Encourage learner reflection.

---

# Acceptance Criteria

- Study workflow is defined.
- Inputs and outputs are documented.
- Personalization remains evidence-driven.
- AI teaching aligns with Phase 3 architecture and Phase 4 philosophy.
