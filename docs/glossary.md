# ARIA Glossary

This glossary defines standard terminology used across ARIA documentation to ensure consistency.

- **learner_concept_state**: The computed and persistent state of a learner’s mastery and confidence for a specific concept. Derived from validated evidence.
- **Evidence Intelligence**: The capability responsible for processing observations into validated evidence.
- **Evidence Memory**: The persistent store of immutable evidence records.
- **Adaptation Intelligence**: The capability that determines how to adjust study sessions based on learner state.
- **Runtime Context**: The active execution state supplied to LLMs during generation.
- **Prompt Template**: Version-controlled definitions that structure the context and instructions sent to LLMs.
- **Logical Agent**: An architectural responsibility boundary defined during Phase 8.
- **Runtime Agent**: The actual orchestrating process executing one or more logical agent responsibilities.
- **Architectural Decision Record (ADR)**: Documentation of significant architectural decisions and their rationale.
