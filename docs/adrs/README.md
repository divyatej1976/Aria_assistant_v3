# Architectural Decision Records (ADRs)

This directory records significant architectural decisions made during the evolution of ARIA.

## Purpose
- Preserve architectural history.
- Document why decisions were made.
- Record alternatives considered.
- Guide future architectural evolution.

## Naming
- ADR-0001-*.md
- ADR-0002-*.md

ADRs should be immutable once accepted. Later changes should create a new ADR rather than rewriting history.
